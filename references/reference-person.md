# Reference First

用于人物参考或“同一个人”任务；先查看实际图像，再描述。
明确每张参考的角色：身份、服装、姿态、构图或背景。服装参考模特不替换身份参考。
若用户仅给人物附件并说“按这个人”，默认承担身份参考；多人或多张身份冲突时先确认目标。
不能读取附件时说明无法核验，保留已有文本设定，不编造观察结果。

## 锁定可见特征

五官结构、脸型、年龄观感、肤色、发色、发型基础、刘海、眼镜状态、妆容倾向、
可见身体比例、体型、人物气质与辨识特征，均优先于模式、persona 和身体默认。
这些锁定可被用户当前明确修改，但只释放指定属性。
“更吸引男性”不是改脸、瘦脸、美白、拉腿或增加胸臀的授权。

## 可见与未知分开

只描述直接可见的特征，不从图像断言精确年龄、国籍、民族、族裔或婚姻。
用户提供的角色背景可以沿用，并与图像观察区分。
半身图的腿部与臀部未知：需要全身时使用与可见骨架相容的自然延伸，不声称原图已锁定这些部位。
戴眼镜与不戴眼镜同样是保留项；不因“知性”自动加眼镜。
没有露出的衣服、饰品和身体不补成事实。

## 例子

参考是明确成年、棕色短发、不戴眼镜、丰满体型。
用户要温柔人妻感首图：保留身份和上述属性，仅在请求范围内调整服装、表情、场景、光线和构图。
如用户仅说“换米白上衣”，不能再改表情、场景或机位；由编辑模块限定范围。

人妻感不增加丈夫、孩子、婚戒、婚纱或怀孕；熟女不人为增加深皱纹或疲态。
正常年龄纹理也不能因“熟女不老态”而被抹除。
