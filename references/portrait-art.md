# 高影响人像美术规则

用于美术细化和质量修复；保留原 V1 的结构、空间、光线和材质原则。
先大形，再中形，最后少量细节。只选当前问题相关的规则。

| 项目 | 可执行指导 |
|---|---|
| 皮肤与面部 | 自然纹理、柔和色差、宽缓明暗和局部高光；保留正常年龄特征，不磨成蜡像，不人为加深皱纹 |
| 眼神与表情 | 写明看向镜头、物体或远方；眼神与动作同向，表情强度自然，不默认放大眼睛 |
| 手部 | 哪只手、触碰哪里、握住什么、如何受力；简单动作优先，手指与道具边缘对应 |
| 头发 | 有重量的发束层级、合理蓬松度和方向性高光；不把每根头发同样锐化 |
| 妆容 | 底妆、眉眼、唇色协调；轻熟清爽、生活柔和、熟女稳重，参考已有妆容优先 |
| 衣料 | 指定一种实际材质及厚度、垂坠、褶皱；棉、针织、丝绸和皮革不能同样反光 |
| 身体体积 | 肩腰胯连续，四肢与躯干体积一致，坐姿体现压缩与支撑 |
| 构图与机位 | 先动作、视线、朝向、接触点及必要入画部分，再决定景别与角度 |
| 全身画面 | 头顶、双腿、鞋完整；非用户刻意裁切时避免边缘切脚 |
| 空间尺度 | 人物大小、桌椅尺度、透视消失方向相容 |
| 遮挡与接触 | 前后层次清楚，手不穿物，脚落地，靠墙或坐下有真实接触 |
| 投影与反射 | 接触阴影、地面投影和反射对应人物位置及主光方向 |
| 光线 | 先一个可解释主光：方向、软硬、强弱、色温；再按需补光，不无理由处处加亮边 |
| 材质响应 | 皮肤宽缓高光、头发沿发束反光、金属高对比、玻璃透明折射；眼镜镜框与镜片分别表现 |
| AI 稀碎感 | 保轮廓、体块、衣服大形和连续明暗，降低无关纹理与碎高光；不靠灰雾掩盖结构错误 |
| 塑料感 | 避免全脸磨皮、全图同锐度、全材质同反光；焦点区域最清楚 |

非写实风格保持插画、动漫、水彩、油画、3D 等用户媒介。
用统一线条、笔触、造型和光影表达成熟，不强塞摄影毛孔、镜头参数或摄影景深。
器材描述仅表达观看意图，不作为真实拍摄证据。
