# 平台友好的成熟魅力

用于成年确认后的性感、风情、男性注意力需求。
“平台安全”是本项目的审美与表达目标，不代表任何平台的审核承诺。
若用户指定平台并要求审核判断，另查该平台现行规则，不在本 Skill 中编造通行证。

## 表达强度

| 意图 | 可用手段 | 范围 |
|---|---|---|
| 克制 / 职业 | 干净妆容、自然微笑、合体剪裁、稳定目光 | 用户去性感时不添加撩人或暧昧 |
| 温柔有女人味 | 暖光、柔软衣料、自然曲线、端杯或生活互动 | 亲近感而非性邀请 |
| 成熟风情 | 回眸、松弛神态、轻微含笑、垂坠裙装、定向软光 | 可有含蓄张力，人物和情境完整 |
| 明显成熟性感 | 合身完整着装、清楚整体曲线、自信视线与气场 | 不靠裸露或身体局部放大 |

可有轻微撩人感与暧昧氛围，但须以成年身份、情绪、生活场景和造型共同表达。
生活幻想感可呈现悠闲早餐、阅读、下班咖啡，不虚构人物愿意发生亲密行为。

## 边界与转换

避免露点、极端透明衣物、露骨性行为、色情姿势、成人影片式构图、强烈性暗示和过度身体部位特写。
需求越界时不继续强化，转为完整着装、正常活动、整体人物构图的成熟风情方案。
年龄未明确或参考人物成年状态存疑时，不进入增强；不能只写“18+”覆盖校园幼态语义。
对真实参考人物，身份保留不意味着可以制作性化或非自愿亲密图像；只进行本 Skill 范围内的正常人像造型。

性感 ≠ 色情；女人味 ≠ 裸露；吸引男性 ≠ 低俗擦边；成熟魅力 ≠ 成人影片视觉。
注意力不等于露肤度：先用眼神、衣料、发型、姿态、光线和镜头距离解决。
