# Hard / Soft Defaults

## Hard Defaults：适用范围内的执行规则

- 明确成年后才能进入本 Skill 的魅力增强流程；年龄模糊不能靠默认年龄解决。
- 不主动学生化、幼态化或改成模板网红少女脸；不抹除参考人物真实特征来“去幼态”。
- 人体结构、骨架、支撑和比例可信；写实皮肤保留自然质感。
- 用户当前明确要求优先，人物参考优先于默认；非写实风格使用对应媒介质感。
- 完全没有模式线索时用人妻感；有模式依据时不覆盖。
- 性感限于明确成年、审美化、平台友好的表达范围；不承诺平台审核结果。

这里的“硬”指执行约束，不是所有人物必须长同一种脸、同一种体型。
对未成年或年龄模糊任务不激活三档默认，也不通过改龄绕过边界。

## Soft Defaults：无人物参考、且对应属性没有任何高优先级设定时才补

| 属性 | 可用起点 |
|---|---|
| 人物背景设定 | 亚洲成年女性，仅用于新建虚构人物，不能从照片推断 |
| 年龄 | 无模式线索时约 32–36 岁；已选模式时用该模式默认范围 |
| 发色与长度 | 黑色或深棕，中长发 |
| 发型 | 自然直发、微卷、低马尾或松散盘发，按场景选一种 |
| 肤色 | 偏白 / 自然白皙；不是审美等级，用户肤色不得被美白默认覆盖 |
| 面部 | 自然协调、柔和轮廓；不强制鹅蛋脸或瘦脸 |
| 体型 | 丰满但不过度肥胖，胸部自然较丰满、臀胯明显、大腿有肉感、腰线柔和 |
| 妆容 | 自然成熟底妆、自然眉眼、豆沙或玫瑰棕等协调色调 |
| 气质 | 温柔、成熟、亲和；明确模式与 persona 优先 |
| 眼镜 | 不默认添加；有账号设定或用户要求才加 |

**Soft Defaults 不是固定模板。** 只补任务需要的字段，不把每一项复制进 Prompt。
瘦高、运动、丰腴、深肤色、白发等明确设定都应保留，不视为需要修复的问题。
有参考人物时，未知下半身用骨架协调的保守延伸，不能直接套默认胸臀体型。
新建 persona 时优先采用其合适的差异化设定；选定后写入人物卡。
