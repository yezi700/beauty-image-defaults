# 成年女性身材优势与视觉塑形

用于明确成年人物的体型表达、曲线需求或男性受众创作。
先保用户与参考体型，再通过衣服、姿态和镜头让已有优势可见。
丰满只是无参考时的软起点，不能使所有人设拥有同一身体。

| 维度 | 可执行表达 | 避免 |
|---|---|---|
| 胸部存在感 | 合体衣料形成自然上身体积，肩带与接缝合理受力 | 自动增大、局部挤压特写、扣子崩裂 |
| 腰臀比例 | 腰线清楚但保留自然宽度，肩腰胯连续过渡 | 蜂腰、任意三围数字 |
| 臀胯曲线 | 侧向 3/4 站姿呈现已有臀胯轮廓 | 极端翘臀、扭曲骨盆 |
| 大腿肉感 | 自然厚度、坐姿接触处轻微压缩 | 无限拉细、腿根局部聚焦 |
| 身体丰满度 | 全身软组织分布一致，手臂与腿部体积协调 | 只有胸臀膨大而四肢极细 |
| 肩腰胯关系 | 保留骨架宽度，服装接缝沿身体走向 | 为曲线缩肩或改变身份 |
| 腿部比例 | 正常髋膝踝关系，高腰衣装改善视觉比例 | 拉长股骨、宽角度畸变 |
| 成年体积感 | 胸廓、腹部、胯部形成连贯体块 | 纸片躯干、塑料充气感 |
| 重量感 | 衣料垂坠、身体压住座椅、脚底承重 | 悬空、没有支撑的姿态 |
| 曲线连续性 | 肩到腰再到胯的轮廓连贯且符合转身透视 | 接缝错位、腰部断折 |

## 服装塑形

- 修身针织、针织裙：厚度和弹性适度，呈现柔和轮廓，不透出私密细节。
- 合体衬衫、成熟女性西装：肩线合适、腰省自然，保留活动余量。
- 高腰裙、包臀裙：用腰线和垂直线条表现比例；步幅和布料拉伸合理。
- 有垂坠感的成熟裙装：用折面和重力表现体积，不把所有面料画成贴皮。
- 吊带加外搭、合身居家服：层次与材质建立生活感，不能自动变内衣场景。
- 合身运动服：体现健康与运动功能，按原体型表现肌肉或柔软度。

## 姿态塑形

轻微侧身、自然 S 曲线、回眸、扶桌、靠墙、站姿重心转移、坐姿腿部自然延伸、自然前倾或转身均可用。
每张选一个主动作，说明重心与接触点；前倾不应变成胸部主导镜头。
回眸时肩颈、躯干和骨盆转向相容；手扶桌必须够得着桌面。

## 镜头塑形

半身保面部与上身体积；3/4 身兼顾脸、腰胯与手势；全身关注整体比例与脚部完整。
优先平视或适度侧向 3/4。轻微低机位只有在不扭曲比例、不窥视衣物时使用。
主体占比为整体人物服务，不做胸、臀、腿根的独立吸睛特写。

示例：保留参考人物自然丰腴体型，米白合身针织裙，站姿重心落在右腿，身体轻微侧向，
脸转向镜头；衣料呈现连贯腰胯曲线，腰部保留自然宽度，平视 3/4 身构图。
