# GPT Image Prompt Adapter

用自然语言表达视觉目标与编辑范围，尤其区分 preserve / modify / do not change。
这些是普通语义标签，可用中文，不是必需关键词、参数或特殊 token。

- 先说明用途及目标：要一张怎样的人物图、给谁看、重点在哪里。
- 明确每张图承担身份、服装还是场景参考，避免混用人物。
- 编辑时将修改与保留分开；必要联动只包含新衣遮挡、阴影等实际变化。
- 连续编辑每轮重申身份和保留项，实际检查漂移；Prompt 不保证像素不变。
- 不因为“更自然”或“更吸引人”重做脸与体型。
- 未指定具体 GPT Image 版本时，不自行声称某个参数或多图限制适用。

## 同一意图示例

```text
制作温柔成熟、面向男性受众的厨房生活首图。使用身份参考中的同一位 34 岁成年女性。
保留（preserve）：五官、脸型、肤色、棕色短发、不戴眼镜状态和自然丰满的身体比例。
修改（modify）：换成不透的米白合身针织上衣，场景改为简洁暖色厨房；身体轻侧，
左手扶台面，含笑看向镜头；平视 3/4 身，侧窗软光使脸清楚、衣料有厚度、腰胯轮廓自然。
不要改变（do not change）：人物身份、年龄和体型；不添加婚戒或家属，不做局部身体特写。
```

若只是换衣，保留原场景、动作、表情和机位，取消上述首图重新设计内容。
写法参考：[OpenAI Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)，2026-10-07。
本项目仅采用明确保留与修改的原则，不绑定文档示例中的特定模型版本或调用参数。
