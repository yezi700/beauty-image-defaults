# Qwen-Image 2.1 Prompt Adapter

将既定视觉意图改写为明确的视觉关系。以下顺序是本项目的写作约定，不是专有语法。
主体 → 人物身份 → 年龄观感 → 外貌 → 体型 → 发型妆容 → 服装 → 动作
→ 表情视线 → 场景 → 构图 → 光线 → 材质 → 风格 → 约束。
有参考时省略未知外貌，明确身份参考用途；不要为了填满字段臆造属性。

- 主语、位置与动作一一对应，如左手扶桌、身体轻侧、脸朝镜头。
- 先写人物与环境关系，再写光线和材质；同义形容词只留有作用的一个。
- 编辑先说明改动，再列不变项；不把保留项写成重新设计清单。
- 不添加未经验证的权重、采样值、特殊 token 或所谓最佳参数。
- 不把 API 中具体部署的名称、尺寸或输入限制当成所有 2.1 接口都支持的能力。

## 同一意图示例

已知：用户设定 34 岁，身份参考为棕色短发、不戴眼镜、自然丰满；换成米白针织上衣并移到暖色厨房，温柔男性向首图。

```text
以人物参考图中的同一位 34 岁成年女性为主体，保留五官、脸型、肤色、棕色短发、
不戴眼镜状态与自然丰满体型。穿不透的米白合身针织上衣，身体轻侧，左手轻扶厨房台面，
温柔含笑看向镜头。暖色厨房背景简洁，平视 3/4 身构图，面部清楚，腰胯轮廓自然连续。
侧窗软光照亮脸与衣料，针织具有真实厚度；保持自然肤质、成熟生活感与整体人物焦点。
不改变身份、年龄和身体比例，不增加婚戒或家属，不使用身体局部特写。
```

例中动作与构图来自首图重构范围；若用户仅换衣，则删掉场景、动作与构图改动。
来源核对：[阿里云 Qwen 图像生成与编辑接口](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)，2026-10-07。
本 adapter 不承诺模型效果优于其他写法，需成图验证。
