# Seedream Prompt Adapter

使用通用自然语言，按任务目标 → 人物 → 改动 → 场景关系 → 视觉表现 → 保留项组织。
这是跨版本保守写法，不宣称 Seedream 有独有语法或保证一致性。

- 说明新图还是编辑、主体是谁、在做什么、画面如何组织。
- 有参考时分别说明身份与服装等用途；输入数量、参考支持依实际版本核实。
- 将抽象“风情”转为含笑视线、自然回眸、合身着装等可见关系。
- 同一要求不要重复同义词或互相冲突的镜头方向。
- 约束写在自然语言中，不虚构权重、特殊 token、负面字段或采样参数。
- 模型版本不明时只交付通用 Prompt，不猜测版本能力。

## 同一意图示例

```text
制作一张面向男性受众的温柔厨房生活首图。人物为身份参考中的同一位 34 岁成年女性，
棕色短发、不戴眼镜、自然丰满体型。换成不透的米白合身针织上衣，将场景改为简洁暖色厨房。
她身体轻侧、左手扶台面，温柔含笑看向镜头。采用平视 3/4 身构图，侧窗软光照亮清楚的脸，
保留自然肤质、针织厚度和连贯腰胯轮廓。保持五官、脸型、肤色、身份、年龄和体型不变，
不添加婚戒或家属，不使用身体局部特写。
```

仅换衣任务需取消新场景、动作和构图，改为保留原图这些部分。
