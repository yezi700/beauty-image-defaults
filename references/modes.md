模式描述气质，不描述婚姻、职业事实或年龄资格。按入口的 Mode 优先级路由。
下表低 / 中 / 高是相对创作方向，不是模型权重、测量结果或受众偏好定律。
身体展示与性感强度均受用户要求、参考人物及平台友好边界约束。

## 如何决定主模式

1. 用户明确指定即采用；“不要熟女”是排除条件，不是触发关键词。
2. 沿用锁定账号主模式；当前用户要求优先于账号设定。
3. 看整体表达重心：都市轻盈 / 生活亲和 / 气场风情。
4. 场景只在气质不足时辅助；都没有时用人妻感。
5. 再单独决定年龄；不能按数字区间分桶。

| 厨房里的冷艳成熟姐姐，强气场 | 熟女 | 气质高于厨房场景 |
| 酒廊里的温柔日常博主，生活感 | 人妻感 | 酒廊不强制熟女 |

模式不自动更换脸型。面部差异主要经神态、妆容与造型表达：
轻熟女清爽，人妻感柔和，熟女稳定；保留原人物正常年龄特征。
