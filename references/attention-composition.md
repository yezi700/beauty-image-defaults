# 封面、首图与缩略图注意力

用于封面、引流图、社交媒体 Feed 首屏与缩略图。
未指定男性受众时只做通用焦点优化；male-directed 再结合成熟表情和人物气质。
以下占比是本项目的构图起点，不是平台标准或效果统计。

## 先确定观看顺序

人物 → 脸 → 身体大形 → 服装轮廓 → 一个核心记忆点。
不要把全部人设道具和精细背景塞进封面。

| 问题 | 操作 |
|---|---|
| 人物太小 | 单人竖幅可先让人物约占画高 65–85%，结合标题与平台裁切调整 |
| 脸不清楚 | 优先半身或 3/4 身，面部不过暗、不被发丝或道具遮住 |
| 视线不明 | 明确直视镜头；回眸时脸仍可辨识，用户指定看物体时保留 |
| 身体大形碎裂 | 保留腰胯连续轮廓，手臂和道具不要同时横挡躯干 |
| 服装融入背景 | 用明度、色温或色彩分离主体，避免所有轮廓发光 |
| 背景抢眼 | 精简物件，减弱次要区域对比，保留一个可解释的生活场景 |
| 光线平散 | 主光聚焦脸及人物主要体块，眼睛与皮肤高光协调 |
| 缺乏记忆点 | 选眼镜、发型、配色或标志性动作之一，不叠满饰品 |

## 景别和裁切

- 半身：适合表情与人设识别；不能为了身材而强制拉远。
- 3/4 身：兼顾脸、服装与自然曲线；裁切避开手指、膝关节等尴尬位置。
- 全身：保留头顶、双腿与鞋，确认缩小后脸仍可识别；否则建议另做近景首图。
- 有标题时预留单侧干净空间，不盖脸；没有文字需求不自动生成口号。
- 画幅依用户或平台需求；未知时可建议竖幅，但不得假称具体平台必用某比例。

## 缩略图验收

成图可用时缩到约 160–240 像素宽检查：人物是否先被看到、脸是否清楚、轮廓是否连贯、记忆点是否仍在。
只有文本时，把这些作为出图验收项，不声称已经验证缩略图效果。
可做两版对照：只改景别或背景对比，身份和服装不变；用实际反馈判断停留效果。
