# 系列一致性

连续更新先建立共用人物卡，后续逐张沿用并记录明确变更。
如无持久记忆或文件授权，把人物卡返回用户以便下次携带，不假称已永久保存。
首次确认的人物参考优先作为身份锚点；新图只有用户指定为身份参考时才替换它。
不要不断用带漂移的最新图替代原始锚点。

## Identity Lock

五官、脸型、年龄观感、肤色、发型基础、可见体型、胸腰臀关系、人物气质、核心人设、主要妆容路线。
不可见特征标为未知，首次得到可靠参考或用户设定后再纳入锁定。

## Persona Lock

穿衣风格、颜色倾向、首饰、眼镜、妆容、身材风格、表情风格和光线倾向。
身材风格指同一身体的呈现方式，不能与 Identity Lock 中的骨架和比例冲突。
两类锁定有重叠时，身份事实优先于人设造型建议。

## 可变项

场景、动作、服装单品、拍摄角度、表情细节、时间、天气和小道具。
可变不等于每张全改；保留一至两个稳定可识别记忆点。
改服装单品应沿用穿衣路线；当前用户明确要求可以为本张作例外。
本张例外不自动改写整个账号设定；用户要求以后都沿用才更新人物卡版本。

## 人物卡示例（虚构新角色）

```text
角色 ID: warm-reader-01 / v1
Age: 34，来源：用户设定
Mode: 人妻感，来源：温柔阅读生活账号
Identity Lock: 柔和长脸、深棕中长微卷发、自然暖肤色、柔和丰满体型
Persona Lock: 细金属框眼镜、米白/焦糖色、自然豆沙妆、温柔直视、暖窗光
记忆点: 细框眼镜 + 米白针织
可变项: 咖啡/阅读/阳台，衣服单品与自然动作
未知: 尚未提供真实参考，脸部身份需首张确认后锚定
```

每张 Prompt 包含同一身份参考用途和关键锁定摘要，再加入本张变化。
实际出图后比较脸型、眉眼距离、发际线、年龄感、肤色和体型，不只比服装风格。
发生漂移时回到身份锚点重做或局部修正；不得以“同类型美女”代替同一个人。
Prompt、人物卡、seed 都不能保证像素级或身份级一致性；不同工具参考支持需实际验证。
