# ✨ Beauty Image Defaults

> **面向成年女性人像生成的 AI Prompt Skill：自动在「轻熟女 / 人妻感 / 熟女」三档之间切换。**

<p align="center">
  <b>🌿 轻熟女 · ☕ 人妻感 · 🥂 熟女</b>
</p>

---

## 💡 这个 Skill 是做什么的？

很多 AI 人像提示词默认会把女性生成成：

- 过度少女化
- 幼态娃娃脸
- 网红模板脸
- 尖下巴 + 夸张大眼
- 身材比例失真
- 过度磨皮和塑料感

这个 Skill 的目标不是“堆美女关键词”，而是让模型更稳定地生成：

> **明确成年、成熟自然、有人物气质、有生活感、有真实身体体积和视觉层次的女性人像。**

它会根据用户描述自动选择三个方向：

| 模式 | 默认视觉年龄 | 核心气质 |
|---|---:|---|
| 🌿 **轻熟女** | 27–34 | 年轻成熟、都市、知性、精致、轻盈 |
| ☕ **人妻感** | 30–38 | 温柔、亲和、生活感、松弛感、成熟女人味 |
| 🥂 **熟女** | 35–45 | 成熟、从容、自信、优雅、有存在感 |

如果用户没有给出足够线索：

> **默认使用「人妻感」模式，约 32–36 岁视觉方向。**

---

# 🔥 自动切换示例

```text
“都市白领，精致通勤，年轻姐姐”
→ 轻熟女

“温柔居家，在厨房喝咖啡，有生活感和松弛感”
→ 人妻感

“成熟女性，优雅、自信、有贵气和存在感”
→ 熟女
```

用户明确说出“轻熟女 / 人妻感 / 熟女”时，直接使用对应档位。

---

# 🧬 核心优先级

```text
用户当前要求
    ↓
当前参考图
    ↓
已锁定人物设定
    ↓
自动档位
    ↓
通用默认画像
    ↓
一般审美建议
```

这意味着：

- 用户指定 30 岁，不会被默认改成 38 岁
- 参考人物是棕发，不会被默认改成黑发
- 参考人物不戴眼镜，不会被强制加眼镜
- 用户上传人物后，档位主要调整气质、服装、妆容、场景和美术方向
- 默认模板不会凌驾于人物身份之上

---

# 🛡️ Reference First

只要用户提供人物参考图，优先保留：

- 五官结构
- 脸型
- 年龄观感
- 肤色
- 发色与发型
- 眼镜状态
- 可见身体比例
- 体型观感
- 人物气质

核心原则：

> **先保身份，再做美术。**

默认画像只补充“用户没有指定、参考图也无法确定”的信息。

---

# ☕ 什么叫「人妻感」？

这里的“人妻感”是一个 **视觉气质标签**，主要指：

**温柔 + 知性 + 成熟 + 亲和 + 生活感 + 松弛感 + 自然女人味**

它不代表真实婚姻状态。

因此不会自动添加：

- 丈夫
- 孩子
- 婚戒
- 婚纱
- 怀孕
- 家庭关系

---

# 🎯 五条关键原则

> **轻熟女 ≠ 少女**

> **人妻感 ≠ 已婚身份**

> **熟女 ≠ 老态**

> **成熟感 ≠ 增加皱纹**

> **女人味 ≠ 过度裸露**

# 🚀 快速使用

### 轻熟女

```text
生成一位 30 岁左右的亚洲轻熟女，
都市白领气质，精致通勤风，知性自然。
```

### 人妻感

```text
生成一位温柔成熟、有生活感和松弛感的亚洲女性，
在温暖的公寓里喝咖啡。
```

### 熟女

```text
生成一位成熟、优雅、自信、有存在感的亚洲熟女，
高级都市时尚写真。
```

### 有人物参考

```text
使用附件中的人物。
保持她的脸、年龄观感、发型和身材，
将整体气质调整为温柔成熟的人妻感，
场景改成暖色调现代公寓。
```

Skill 会优先保留人物身份，而不是套用默认模板重做一个人。

# 🧠 为什么不是简单写年龄？

因为“30 岁”“35 岁”“40 岁”本身无法稳定控制最终气质。

真正影响成熟感的还有：

- 面部软组织
- 神态
- 妆容
- 发型
- 身体体积
- 服装
- 姿态
- 场景
- 光线
- 画面节奏

所以这个 Skill 使用的是：

> **年龄观感 + 气质 + 人像美术 + 场景语义**

而不是单纯依赖年龄数字。

# 🧩 适合什么模型？

这个 Skill 主要用于自然语言图像生成 / 编辑工作流，例如：

- GPT Image
- Qwen-Image
- Seedream
- Gemini Image
- FLUX
- SDXL
- 其他支持自然语言 Prompt 的模型

它本身不绑定某一个具体模型。

# ⭐ 设计目标

这个项目追求的不是：

```text
masterpiece, 8K, ultra detailed, beautiful woman...
```

而是：

**人物身份稳定**

**年龄观感正确**

**气质明确**

**身体比例自然**

**构图合理**

**光线可信**

**材质真实**

**画面主次清楚**

最终目标：

> **让 AI 生图提示词更像一个懂人物、懂摄影、懂成熟审美的视觉导演写出来的。**
